# BJJ Graph access and sign-in

Public website: https://bjjgraph.org/

## Public access

No account, API key, payment, or authentication is needed to read public guides,
explore positions and techniques, or use the public read-only resources described
at https://bjjgraph.org/api.md. Start anonymously; sign-in is optional.

## Personal progress

Visitors can use the study tools without signing in. Progress stays in that browser.
Optional sign-in with Google or email and password syncs personal training progress
across devices. The user completes sign-in through the website's account controls.

There is no public API for agents to create accounts, authenticate on someone's
behalf, read private progress, or change training records. There is no agent OAuth
server or delegated scope to discover. Do not request passwords or session tokens
in chat. If a user wants sync, send them to the website to sign in themselves.
